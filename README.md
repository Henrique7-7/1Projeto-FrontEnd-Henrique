# Catalogo de Roupas Fitness
O Projeto tem como foco desenvolver um Catalogo de uma loja de roupas Fitness.
A pagina apresentara produtos como camisetas, shorts, leggings, tops e conjuntos esportivos.
O catalogo tera informacoes como nome, preco, categoria, descricao e imagens dos produtos.
O projeto sera desenvolvido durante a disciplina utilizando tecnologias de desenvolvimento Front-end.
